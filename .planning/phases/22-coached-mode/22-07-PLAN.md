```ts
export interface TurnToScore { turnIndex: number; studentText: string; precedingAvatarText: string | null }
export interface TurnScore { turnIndex: number; evidencesCompetency: boolean; score: number | null; rationale: string }
export type TurnScorer = (args: { competencyKey: CompetencyKey; turns: TurnToScore[] }) => Promise<TurnScore[]>;
export async function scoreTurnsForCompetency(args: {
  userId: string; reportId: string; competencyKey: CompetencyKey; turns: TurnToScore[];
}, opts?: { scorer?: TurnScorer }): Promise<TurnScore[]>
```
- CACHE FIRST: `prisma.momentCompetencyScore.findMany({ where: { userId,
  reportId, competencyKey, turnIndex: { in } } })`. Only uncached turns go to the
  scorer; results are persisted with `createMany({ skipDuplicates: true })`
  including `model` (env `COACH_MODEL || "gpt-4.1"`, or `"stub"` when a scorer is
  injected). Return cached + new, ordered by turnIndex.
- `defaultTurnScorer`: ONE model call per report (all its candidate turns
  batched), mirroring the OpenAI usage pattern in `lib/study-plan/checks/grade.ts`
  (dynamic `import("openai")`, timeout, `response_format: { type: "json_object" }`).
  System prompt: given ONE competency (label + description from `COMPETENCIES`,
  plus the rubric dimension keys mapping to it from `DIMENSION_TO_COMPETENCY`),
  for each numbered student turn (shown with the other person's preceding line as
  context), decide whether the turn actually bears on this competency and, if so,
  score 1 (clearly weak) to 5 (exemplary) with a one-sentence rationale. Greetings,
  logistics and acknowledgements do not evidence any competency.
- VALIDATE before persisting, discard-and-retry up to 2 extra attempts, NEVER
  repair: output must contain every requested turnIndex exactly once and no
  others; `score` an integer 1..5 when `evidencesCompetency` true, null when false;
  rationale non-empty and ≤ 400 chars. After exhausting retries, throw
  `TurnScoringFailedError` (exported) — the caller decides on the fallback.
- Header: why this exists (no per-turn data anywhere; session-level `asScoreMap`
  only), cost note (one call per uncached report, cached forever per
  report/turn/competency), privacy note citing 22-COACH-LAYER-DECISION.md
  "Privacy scope".

Steps:
1. (`selectCoachedMoments` only) Load the step's `path.studyPlan.sourceReportIds`
   scoped by `path: { userId }`; everything below is `selectCoachedMomentsFromReports`.
2. `loadGenerationSources(userId, reportIds, { readTranscript: opts?.readTranscript })` — the ONLY source of transcripts and
   moments (REQ-123). Do not query transcripts any other way.
3. `loadCoachedEvidence(userId, reportIds)` (22-04): keep only reports in that
   competency's `scoredReportIds` — a moment from a session that never scored the
   competency is not a candidate.
4. Candidates = `sources.moments` from those reports. Compute each moment's
   `position` (FIRST/MIDDLE/LAST among that transcript's student turns, from
   `sources.transcriptsByReportId`) and drop pleasantries with `isPleasantry`
   BEFORE scoring (no model call spent on "Hi, nice to meet you").
   Then pass each report's remaining candidates through
   `prepareMomentsForGeneration({ requestingUserId: userId, moments,
   momentOwnerUserIds, selfNames: sources.selfNames })` from
   `lib/study-plan/moment-boundary.ts` — its header calls it "The ONLY path by
   which transcript text may reach a model call". Only its survivors are
   candidates, in BOTH bases (a moment the boundary drops can never later reach the
   coach prompt either). Record `droppedForRedaction`/`droppedForCap` counts in the
   warn log when non-zero (counts only, no text).
5. Per report, `scoreTurnsForCompetency(...)`, reports in parallel
   (`Promise.allSettled`). Build `RankableMoment[]` and `rankCoachedMoments`.
   basis = "PER_TURN_SCORE".
6. FALLBACK, deliberate and recorded: only if EVERY report's scoring rejected with
   `TurnScoringFailedError` (or a model/network error), use
   `sources.momentsByCompetency.get(competencyKey)` with
   `rankCoachedMomentsByGrowthArea`, basis = "GROWTH_AREA_FALLBACK", and
   `console.warn` with the step id and the error class names (no student text).
   Partial failure is NOT a fallback trigger: rank what scored.
6b. NO SCORE CUTOFF (W1): ranking keeps every `isQualifyingMoment` survivor;
   `framing` comes from `replayFraming`/`freshFraming`. A best moment scored 4 or
   5 is selected and marked REFINEMENT. It is never dropped.
7. `replay === null` (no turn qualifies at all) → throw `NoQualifyingMomentError`, defined and exported in
   THIS module (not `runtime.ts`'s `NoEligibleReplayTargetError`, which would
   create a runtime↔selection import cycle; 22-12 maps one to the other).
   `studentText` is returned VERBATIM (comment it).
