```ts
export type TurnPosition = "FIRST" | "MIDDLE" | "LAST"; // among STUDENT turns only

export interface RankableMoment {
  reportId: string;
  turnIndex: number;
  studentText: string;          // verbatim; never trimmed by this module
  position: TurnPosition;
  reportCreatedAt: Date;
  linkedGrowthAreaCount: number;
  evidencesCompetency: boolean | null; // null = unscored
  score: number | null;               // 1..5, null when unscored/not evidencing
}

export type MomentRejection = "PLEASANTRY" | "NOT_EVIDENCING" | "UNSCORED";
export type MomentFraming = "REWORK" | "REFINEMENT";

export interface RankedMoments {
  replay: RankableMoment | null;
  fresh: RankableMoment | null;  // null = thin evidence
  replayFraming: MomentFraming | null;
  freshFraming: MomentFraming | null;
  rejected: Array<{ moment: RankableMoment; reason: MomentRejection }>;
}

export const MIN_SUBSTANTIVE_WORDS = 8;          // PROVISIONAL UNTIL CALIBRATED
export const MIN_SUBSTANTIVE_WORDS_AT_EDGE = 15; // FIRST/LAST turns
export const MAX_REWORKABLE_SCORE = 3;           // PREFERENCE, not a filter: above it = REFINEMENT framing
export const PLEASANTRY_PATTERNS: ReadonlyArray<RegExp>;
export function substantiveWordCount(text: string): number;
export function isPleasantry(text: string, position: TurnPosition): boolean;
/** THE qualification predicate, shared by ranking AND 22-07's path-placement guard: not a pleasantry, scored, and evidences the competency. No score cutoff. */
export function isQualifyingMoment(m: RankableMoment): boolean;
export function momentFramingFor(score: number | null): MomentFraming; // score > MAX_REWORKABLE_SCORE -> REFINEMENT
export function rankCoachedMoments(moments: ReadonlyArray<RankableMoment>): RankedMoments;
export function rankCoachedMomentsByGrowthArea(moments: ReadonlyArray<RankableMoment>): RankedMoments;
```

Rules:
- `PLEASANTRY_PATTERNS` (case-insensitive, word-boundary) covers at least:
  greetings (hi, hello, hey, good morning/afternoon/evening), "nice/great/
  pleased to meet you", "thank(s| you)( so much)?( for having me| for your time|
  for the opportunity)?", "I'm ready( to (begin|start|get started))?( the
  interview)?", "ready when you are", "let's (begin|get started|start)", "can you
  hear me", "sounds good", "(yes|yeah|sure|okay|ok|great|perfect|absolutely)" as
  standalone acknowledgements.
- `substantiveWordCount`: strip every PLEASANTRY_PATTERNS match, then count the
  remaining word tokens.
- `isPleasantry(text, position)`: true when `substantiveWordCount(text)` is below
  `MIN_SUBSTANTIVE_WORDS_AT_EDGE` for FIRST/LAST, or below `MIN_SUBSTANTIVE_WORDS`
  for MIDDLE. This is BOTH filters: content (strip-then-count) applies at every
  position; position raises the bar at the edges. A rule keyed on position alone
  fails 22-CONTEXT.md.
- `rankCoachedMoments`: reject, recording the reason, in this order: PLEASANTRY,
  UNSCORED (`evidencesCompetency === null`), NOT_EVIDENCING (false). Survivors are
  exactly the moments for which `isQualifyingMoment` is true. There is NO score
  cutoff: 22-CONTEXT.md says "lowest-scored", and a high-scoring best moment still
  runs as a session, framed as refinement (`momentFramingFor`). Sort survivors by: score asc, then
  linkedGrowthAreaCount desc, then reportCreatedAt desc, then turnIndex asc, then
  reportId asc (a declared final tie-break — never array order). `replay` = first.
  `fresh` = the first later survivor from a DIFFERENT report if any exists,
  otherwise the next survivor from the same report that is a different turnIndex;
  null if neither. `replayFraming`/`freshFraming` = `momentFramingFor(score)` of
  each (null when that moment is null). Input array order must not change the
  result.
- `rankCoachedMomentsByGrowthArea` (the recorded fallback basis): same pleasantry
  filter; treats every non-pleasantry moment with `linkedGrowthAreaCount > 0` as
  evidencing; sorts by linkedGrowthAreaCount desc, reportCreatedAt desc,
  turnIndex asc, reportId asc; same fresh rule.

RED cases (exact expectations):
1. `isPleasantry("I'm ready to begin the interview.", "FIRST")` → true; the same
   string at "MIDDLE" → true (content alone excludes it).
2. "Hi, nice to meet you." at MIDDLE → true.
3. "Hi, nice to meet you. In my last role I led a twelve-person team through a
   reorganisation that cut our release cycle in half." at FIRST → false.
4. "Thanks, that's great." at MIDDLE → true.
5. A 10-substantive-word line at FIRST → true; the same line at MIDDLE → false
   (proves the edge bar is higher, not identical).
6. Ranking: a moment list where "I'm ready to begin the interview." is scored 1
   (lowest) → it is in `rejected` with PLEASANTRY and is NOT `replay`.
7. Scores [3, 2, 5, unscored, not-evidencing] → replay is the 2, fresh is the 3,
   the 5 is a survivor (not rejected), the unscored/not-evidencing carry their
   reasons; `replayFraming === "REWORK"`.
7b. ALL-HIGH-SCORES: scores [4, 5] on qualifying turns → replay is the 4 with
   `replayFraming === "REFINEMENT"`, fresh is the 5 with REFINEMENT, `rejected`
   is empty. (Proves the threshold is a preference, not a dead end.)
7c. `isQualifyingMoment` is false for a pleasantry, an unscored turn and a
   not-evidencing turn, and true for a score-5 evidencing turn.
8. Only one qualifying moment → `fresh === null`.
9. Two qualifying moments in report A (scores 1, 2) and one in report B (score 3)
   → replay = A's 1, fresh = B's 3 (different report preferred).
10. Tie on score → more growth areas wins; then more recent report; then lower
   turnIndex.
11. Shuffled input (3 permutations) → deep-equal `replay`/`fresh`.
12. `replay.studentText` is the identical string object/value passed in — not
   trimmed (input with leading/trailing spaces comes back unchanged).
13. `rankCoachedMomentsByGrowthArea`: moments with zero growth areas never selected;
   pleasantry with 2 growth areas still rejected.
