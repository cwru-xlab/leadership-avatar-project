**coach.ts:**
```ts
export const SOFT_CAP_ATTEMPTS_PER_LEG = 4;      // ADVISORY, PROVISIONAL UNTIL CALIBRATED
export const SOFT_CAP_COACH_TURNS_PER_LEG = 12;  // ADVISORY, PROVISIONAL UNTIL CALIBRATED
export const MAX_COACH_GENERATION_ATTEMPTS = 3;
export interface CoachTurnDeps { generate?: (system: string, history: Msg[]) => Promise<unknown>; grade?: Grader }
export async function coachTurn(args: {
  userId: string; coachedSessionId: string; leg: "REPLAY" | "FRESH"; legCount: 1 | 2; momentFraming: "REWORK" | "REFINEMENT";
  moment: { counterpartLine: string | null; studentLine: string };
  coach: CoachIdentity; competency: {...}; rubricDimensions: [...]; underlyingTypeName: string;
  utterance: { text: string; spokenDurationMs: number } | null;
}, deps?: CoachTurnDeps): Promise<CoachTurnResult>
export function legStateFromTurns(turns: CoachedTurnRow[], leg): { attemptsInLeg; demonstrationsInLeg; coachTurnsInLeg; awaiting; legReady; lastAttempt; hasOpened }
```
`coachTurn` does NOT read S3 or the step (the caller, 22-12's runtime, resolves the
moment and ownership); it reads/writes only `CoachedSession`(ownership re-checked
by `userId`) and `CoachedTurn`. Steps:
1. Load the session (scoped by userId, not COMPLETE) and this leg's turns ordered
   by seq; `legStateFromTurns`.
2. `utterance === null`: allowed only to OPEN (no coach turn yet in leg) or RESUME
   (turns exist) — `isOpening`/`isResume` passed to the prompt. Otherwise reject
   with `CoachTurnOrderError` when `legReady` already true.
3. `utterance` present: require `hasOpened` and `spokenDurationMs > 0` (attempts
   are spoken; reject otherwise with `UnspokenAttemptError`). Kind = `awaiting ===
   "ATTEMPT" ? "ATTEMPT" : "REPLY"`. For ATTEMPT: `parroted =
   lastDemonstration ? isParrotOf(text, lastDemonstration) : false`; grade;
   `acceptable = !parroted && grade.acceptable`. Persist the STUDENT row (text
   VERBATIM from transcription, score, acceptable, parroted, gradeRationale,
   spokenDurationMs).
4. Compute `demonstrationAllowed = attemptsInLeg >= 1 && demonstrationsInLeg <
   MAX_DEMONSTRATIONS_PER_LEG && lastAttempt?.acceptable !== true`;
   `softCapReached = attemptsInLeg >= SOFT_CAP_ATTEMPTS_PER_LEG ||
   coachTurnsInLeg >= SOFT_CAP_COACH_TURNS_PER_LEG`.
5. Generate (up to MAX_COACH_GENERATION_ATTEMPTS), DISCARD-AND-RETRY, never
   repair. Each candidate must pass, in order: shape (`move` in COACH_MOVES,
   `awaiting` valid, `speech` non-empty string); `validateCoachSpeech(speech, {
   studentLine, counterpartLine, studentAttempts })`; if `demonstration` non-null:
   `assertTipSafe(demonstration, { studentLine, gate: { kind: "DEMONSTRATION",
   attemptsInLeg, demonstrationsInLeg } })` and `move === "DEMONSTRATE"`;
   `move === "LEG_DONE"` only if the leg has an acceptable attempt OR
   (`softCapReached` AND attemptsInLeg ≥ 1) — set `closedAtSoftCap` accordingly;
   `move === "OPEN"` only when isOpening. Log each rejection reason (no student
   text).
6. All attempts rejected → deliver a fixed, gate-passing fallback composed here
   (e.g. "Let's stay with that moment. What were you aiming to get across?",
   move ASK_DIAGNOSIS, awaiting REPLY, demonstration null) — and re-run
   `validateCoachSpeech` on it too; log at warn.
7. Persist the COACH row (next seq; catch P2002 on `@@unique([coachedSessionId,
   seq])` by re-reading and retrying once). Return `{ coachTurn: { speech, move,
   awaiting, demonstration }, legState }`.
