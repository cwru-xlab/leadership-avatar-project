```ts
export const EVALUATION_JSON_SCHEMA = {
  name: "interview_evaluation",
  strict: true,
  schema: {
    type: "object",
    additionalProperties: false,
    required: ["visual_score", "vocal_score", "content_score", "behavioral_score", "report_markdown"],
    properties: {
      visual_score:     { type: ["integer", "null"], minimum: 1, maximum: 5 },
      vocal_score:      { type: ["integer", "null"], minimum: 1, maximum: 5 },
      content_score:    { type: ["integer", "null"], minimum: 1, maximum: 5 },
      behavioral_score: { type: ["integer", "null"], minimum: 1, maximum: 5 },
      report_markdown:  { type: "string" },
    },
  },
} as const;
```
(If OpenAI rejects `minimum`/`maximum` under `strict: true`, drop those two keywords from
the schema — the validator below is the real enforcement. Keep `strict: true`.)

Export types:
```ts
export interface RawEvaluation {
  visual_score: unknown; vocal_score: unknown;
  content_score: unknown; behavioral_score: unknown;
  report_markdown: unknown;
}

export interface ValidatedEvaluation {
  visualScore: null;            // typed null — Phase 8 widens this
  vocalScore: null;
  contentScore: number | null;
  behavioralScore: number | null;
  reportMarkdown: string;
}
```

Export `validateEvaluationResult(raw: unknown): ValidatedEvaluation`:
- Internal `coerceScore(value: unknown): number | null` — returns the value only if it is a
  `number`, `Number.isInteger`, and between 1 and 5 inclusive. Everything else (strings like
  `"4"`, `4.5`, `0`, `6`, `NaN`, `null`, `undefined`) returns `null`. Do NOT parse strings —
  a string score means the model ignored the schema and should not be trusted.
- `visualScore` and `vocalScore` are ALWAYS `null`, discarding whatever the model returned.
  Add a comment: "Enforced in code, not just in the prompt. Phase 8 supplies real metrics."
- `reportMarkdown`: must be a non-empty string after trim, else throw
  `new Error("Evaluator returned an empty report body")` so the caller records FAILED rather
  than storing a blank report.

Export `hasAnyScore(e: ValidatedEvaluation): boolean` — true if either content or behavioral
is non-null. The API layer uses it to decide whether a READY report is meaningful.

Append to `lib/interview/evaluation.ts`.

```ts
export interface EvaluationInput {
  /** Speaker-labeled transcript text. Produced by formatTranscriptForEvaluator. */
  fullTranscript: string;
  /** Snapshot of the candidate's extracted resume text. "" when skipped. */
  resumeText: string;
  roleContext: { roleTitle: string; industry: string; difficulty: string };
}

export interface EvaluationOutcome {
  ok: true;  result: ValidatedEvaluation; model: string;
}
export interface EvaluationFailure {
  ok: false; reason: string; model: string;
}

export async function runInterviewEvaluation(
  input: EvaluationInput
): Promise<EvaluationOutcome | EvaluationFailure>
```

Implementation:
- `const model = process.env.INTERVIEW_EVAL_MODEL || "gpt-4.1";` — default matches the
  interview chat route (`app/api/interaction/chat/route.ts:189`) and the case evaluator.
- Budget, mirroring `app/api/interaction/finish/route.ts`: total 50s, RETRIES = 1, so
  per-attempt timeout = 25s. Construct the client with
  `new OpenAI({ apiKey: process.env.OPENAI_API_KEY, timeout: PER_ATTEMPT_TIMEOUT, maxRetries: 0 })`
  and do the single retry yourself (with a 1s delay) so a retry is logged and the reason is
  attributable. Import lazily: `const OpenAI = (await import("openai")).default;`
- Messages: system = `INTERVIEW_EVALUATOR_PROMPT` verbatim (imported from `./prompts`).
  User message = a labeled block of the declared inputs, matching the names the prompt uses:

  ```
  full_transcript:
  <input.fullTranscript>

  resume_text:
  <input.resumeText or "(No resume was provided.)">

  role_context:
  { "role_title": ..., "industry": ..., "difficulty": ... }

  visual_metrics: null
  vocal_metrics: null
  ```
  State `visual_metrics: null` and `vocal_metrics: null` explicitly — the prompt's CRITICAL
  RULE keys off them being null, so omitting the keys is worse than sending null.
- Call `openai.chat.completions.create({ model, messages, max_tokens: 4000, response_format: { type: "json_schema", json_schema: EVALUATION_JSON_SCHEMA } })`.
- Parse `completion.choices[0]?.message?.content` with `JSON.parse`, then run it through
  `validateEvaluationResult`. Any throw (network, timeout, parse, empty body) is caught.
- Retry loop: attempt 1, on failure log `console.warn` and retry once; on second failure
  return `{ ok: false, reason, model }` where `reason` is an operator-readable one-liner
  like `"Evaluation failed after 2 attempts: <error message>"`. Truncate `reason` to 500 chars.
  NEVER throw out of this function — the caller must always be able to record FAILED.
- Log on success: `console.info("Interview evaluation completed", { model, contentScore, behavioralScore, markdownLength })`.
  Never log the transcript or resume text.
