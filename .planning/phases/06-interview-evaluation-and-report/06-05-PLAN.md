**HARD CONSTRAINTS:**
1. Ownership comes from the authenticated JWT user only. `findFirst({ where: { id, userId: currentUser.id } })`.
   Never `findUnique({ where: { id } })` followed by a comparison — one early return away from a leak.
2. A report owned by someone else returns **404 with the exact same body and status as a
   nonexistent report**. Never 403, never a distinguishable message. This makes the
   cross-student denial test unambiguous.
