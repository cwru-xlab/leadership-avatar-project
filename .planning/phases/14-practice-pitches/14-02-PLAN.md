   - `adjustableRangeSeconds?: [number, number] | null` — the inclusive range a
     student may move the session budget into before starting. Doc comment:
     "CONTEXT.md: session length is PROPOSED and student-adjustable. The proposal

     `required` is true, which is what distinguishes it from `case-study`, whose
     instance is authored elsewhere and addressed by id."

4. `InstanceConfig` — add two members to the discriminated union:
   - `{ kind: "pitch-elevator"; pitchSubject: string; listenerKnowledge: "blind" | "name-role" | "full-profile" }`

     category list (CONTEXT.md). `listenerKnowledge` is a student-selected wizard

     property of any scenario record."

**`lib/engine/termination.ts`** — extend `resolveTermination` to take the turn
position and enforce the floor:
- New signature: `resolveTermination({ policy, source, reason, assistantTurnCount })`.
  Make `assistantTurnCount` optional so Phase 13's existing call sites compile
  unchanged; when `policy.avatarEndFloor` is set and `assistantTurnCount` is
  missing, FAIL CLOSED (reject the termination) rather than letting an unmeasured
  session end.
- Gate order, documented in the function body: (1) `source: "avatar"` requires
  `policy.avatarMayEnd`; (2) the reason must be in `policy.avatarEndReasons`
  (unchanged — the model may not invent a reason vocabulary); (3) NEW — if
  `policy.avatarEndFloor` is set, require
  `assistantTurnCount >= policy.avatarEndFloor.minAssistantTurns`, else return
  `{ ok: false, reason: "floor-not-met" }` with `recordedReason: null`.
- Header comment addition: "The floor exists so every session yields gradeable
  material (CONTEXT.md 14: 'gated by a floor — it may never end before a minimum
  has happened'). A rejected termination means the session CONTINUES; nothing about
  the student's turn is cut short and no error surfaces to the student."
- A rejected-by-floor termination must still strip the marker from the
  student-visible text — `parseTerminationMarker` already does this and must not be
  made conditional. The student must never see a stray marker.

**`lib/engine/time-budget.ts`** — two additions:
- Extend `computeTimeBudgetState` to also return
  `firstTurnWindow: { windowSeconds: number; elapsedSeconds: number; overBy: number } | null`,
  computed from a new optional `firstTurn: { startedAt, deliveredAt? }` argument and
  `config.timeBudget.firstTurnWindowSeconds`. `null` when the type declares no
  window (every Phase 13 type). Keep `now` as an argument — the function stays pure.
- Extend `buildTimeBudgetFragment(state)` so that when `firstTurnWindow` is present
  it appends a short fragment in the SAME tail-block style as the existing one.
  Three phrasings: within the window; past the window and still going (the one that
  licenses impatience — e.g. "the speaker has now been talking for 84 seconds
  against a 60-second window; a listener would be getting restless"); and
  concluded-over-window (for the follow-up phase). Keep it to one or two sentences —
  this is prompt tail content, not a report.
- Add `clampAdjustableBudget(config, requestedSeconds)` →
  `{ seconds: number; clamped: boolean }`. Returns the type's declared
  `timeBudget.totalSeconds` untouched when `adjustableRangeSeconds` is absent;
  otherwise clamps `requestedSeconds` into the inclusive range. Pure, no I/O.
- The existing file-header comment forbidding system-prompt use must be extended to
  cover the new fragment explicitly, naming REQ-73.

**`lib/report/snapshot.ts`** — add
`type PitchInputSnapshot = { kind: "pitch"; pitchKind: "elevator" | "deck"; pitchSubject: string | null; listenerKnowledge: "blind" | "name-role" | "full-profile" | null; deckId: string | null; slideCount: number | null; askPriceUsd: number | null; askEquityPct: number | null; fairValueBand: { priceUsdMin: number; priceUsdMax: number; equityPctMin: number; equityPctMax: number } | null; firstTurnWindowSeconds: number | null; budgetSeconds: number | null; listenerPersona: string | null }`

field here is SESSION-CONSTANT, captured at start and never re-fetched — the

Do NOT change any existing member's shape.
