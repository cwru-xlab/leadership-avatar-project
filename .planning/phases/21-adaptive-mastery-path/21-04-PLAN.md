<objective>
Build the mechanical half of 21-CONTEXT.md's first named guardrail: never misquote
the student. A question quoting the student must reproduce what they ACTUALLY
said, verbatim, with its originating moment — and 21-CONTEXT.md states this is
"mechanically checkable against the stored transcript, and should be."

Purpose: a model asked to quote a transcript will paraphrase, tidy grammar, merge
two turns, or invent. A prompt instruction not to do that is not a guarantee. The
guarantee is a function that rejects any quote not byte-present in the stored
turn — and rejection, not repair, because a repaired quote is the model's text
wearing the student's name.

This is a TDD plan: the behaviour is a pure function with defined input and
output, and the near-miss cases are exactly where a hand-written implementation
goes soft.

Output: `validateVerbatimQuote`, `extractSessionMoments`, and an adversarial
verifier.
</objective>

<feature>
  <name>Verbatim quote validation</name>
  <files>lib/study-plan/verbatim.ts, scripts/verify-verbatim-quote.ts</files>
  <behavior>
`validateVerbatimQuote(quote: string, transcript: InterviewTranscript, opts?: {
expectedTurnIndex?: number }): VerbatimQuoteResult`

`VerbatimQuoteResult` is a discriminated union:
`{ ok: true; reportId: string; turnIndex: number; turnRole: "user"; charStart: number; charEnd: number }`
or
`{ ok: false; reason: VerbatimRejectReason; detail: string }`

`VERBATIM_REJECT_REASONS` = `"EMPTY_QUOTE" | "NOT_FOUND_IN_ANY_TURN" |
"FOUND_ONLY_IN_ASSISTANT_TURN" | "SPANS_MULTIPLE_TURNS" | "AMBIGUOUS_MULTIPLE_MATCHES" |
"TURN_INDEX_MISMATCH" | "TOO_SHORT"`.

Cases (write these as the RED tests first):

ACCEPT:
- Quote is an exact substring of exactly one `role: "user"` turn → ok, with that
  turn's index and the character offsets.
- Quote is the entire content of one user turn → ok.
- Quote contains internal punctuation, double spaces, or a filler word
  ("um, I guess I'd, like, push back") and matches exactly → ok. The student's
  disfluencies are part of what they said; stripping them is a misquote.

REJECT:
- `""` or whitespace-only → `EMPTY_QUOTE`.
- Quote shorter than 12 characters → `TOO_SHORT`. A three-word fragment matches
  by accident and proves nothing about what the student meant.
- Quote differs by ONE character (a comma removed) → `NOT_FOUND_IN_ANY_TURN`.
  This is the case that must not be fuzzy-matched.
- Quote differs only in case → `NOT_FOUND_IN_ANY_TURN`. Matching is
  case-SENSITIVE.
- Quote has a trailing period the turn lacks → `NOT_FOUND_IN_ANY_TURN`.
- Quote is grammatically tidied ("I would push back" vs stored "I'd push back")
  → `NOT_FOUND_IN_ANY_TURN`.
- Quote is the concatenation of the tail of turn 3 and the head of turn 5 →
  `SPANS_MULTIPLE_TURNS` (detected because it matches no single turn while its
  halves match two).
- Quote appears in an `assistant` turn only → `FOUND_ONLY_IN_ASSISTANT_TURN`. The
  avatar's words are never attributed to the student.
- Quote appears identically in two different user turns →
  `AMBIGUOUS_MULTIPLE_MATCHES`. Without a unique turn there is no "originating
  moment", which REQ-110 requires.
- `expectedTurnIndex` supplied and the match is at a different index →
  `TURN_INDEX_MISMATCH`.

NORMALIZATION POLICY — the only permitted normalization is Unicode NFC on both
sides, applied symmetrically, because a transcript turn and a model's echo of it
can differ in composed-vs-decomposed accents without differing in what was said.
Nothing else: no trimming, no case folding, no whitespace collapsing, no smart-quote
folding. Document that policy in a block comment and name each rejected
normalization, because every one of them is a tempting bug fix that would quietly
turn the guarantee off.

The function performs NO model call, NO network access, and NO S3 read — the
caller supplies the already-fetched transcript. Keeping I/O out is what makes the
battery runnable with zero credentials.
  </behavior>
