  <name>Task 1: Write the person-generation prompt and model call</name>
  <files>lib/networking/person-generation.ts</files>
  <action>
Read `app/api/interview/persona/distill/route.ts` end to end FIRST — especially the
constants block (lines 9-15), the retention comment (lines 56-70) and
`distillPersona` (line 133 onward). This module is its sibling, not its extension.

Create `lib/networking/person-generation.ts` exporting:

- `MAX_HINT_LENGTH = 300` — the hint is one free-text box, not structured fields
  (16-CONTEXT.md discretion item; 16-RESEARCH.md recommends free text, consistent
  with Phase 14's free-text pitch subject).
- `MAX_GENERATED_DESCRIPTION_LENGTH = 700` — target 2-4 sentences / roughly 300-500
  characters with headroom. Doc comment: "Sized to sit far inside the distill route's
  `MAX_PROFILE_TEXT_LENGTH = 4000` and to stay comfortably editable in a textarea."
- `PERSON_GENERATION_SYSTEM_PROMPT` — a plain-prose system prompt instructing the
  model to: invent ONE plausible, fictional professional person consistent with the
  student's hint; give them a name, an employer described generically (an invented
  company name is fine, a real one is not), a seniority, a field, a few years-in
  detail and a manner; write it as 2-4 sentences of third-person narrative prose in
  the register of a LinkedIn "about" blurb; output PROSE ONLY, no markdown, no bullet
  list, no headings, no preamble such as "Here is"; never claim to describe a real,
  identifiable individual; and never produce a second-person role-play instruction
  (that is the distiller's job downstream). Add a comment above the prompt string
  stating plainly that this text will be EDITED BY A HUMAN before it is distilled, so
  being slightly wrong is recoverable and refusing to commit to specifics is not.
- `generatePersonDescription(hint: string): Promise<{ description: string }>` — one
  non-streaming JSON-mode-free text completion via `await import("openai")`, same
  client construction and 20s timeout as `distillPersona`. Trim the hint to
  `MAX_HINT_LENGTH` before sending; trim the output to
  `MAX_GENERATED_DESCRIPTION_LENGTH`; strip any leading "Here is"/"Sure"-style
  preamble and any surrounding quotes with a small deterministic cleanup helper
  (export it if that makes it testable). Throw on an empty result — the route turns
  that into a 502.

File header comment must state: (a) this is a SEPARATE model call from Phase 8's
persona distiller and deliberately does not share its prompt (16-CONTEXT.md decision
2); (b) the RETENTION posture — hint and output are used for exactly one
non-streaming model call, never written to Prisma, S3 or any cache, never logged
beyond lengths; (c) output is description text, NOT a persona sentence — the Phase 8
distiller still does the persona shaping.
  </action>
