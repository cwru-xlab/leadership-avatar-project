- **INVISIBLE REFACTOR (REQ-69).** The generic shell must reproduce today's interview
  session UI exactly: same layout, same controls, same copy, same speakable-chunk
  streaming behavior, same progress display.
- **Do NOT edit `components/interview/InterviewSessionShell.tsx` in this plan.** Port
  FROM it into a new file. It stays live until plan 13-13 deletes it, so a problem
  here is recoverable by reverting one new file instead of breaking the only working
  shell. (`app/interview/[type]/page.tsx` still renders it.)
- **Do NOT edit `app/case-play/[caseId]/page.tsx`.** Plan 13-11 owns it.
- `cameraMode` is a prop the shell CANNOT change — preserve the existing type-level
  enforcement, which is how REQ-35's lock is held by the compiler rather than by
  convention. Do not loosen the prop type.
- **The camera-stream-start re-entry guard is load-bearing.** STATE.md records a past
  defect class where an avatar reconnect re-invoked the capture start path while the
  first request was still pending, and the fix was a SYNCHRONOUS in-flight guard.
  Carry that guard across verbatim. Treat HeyGen session start/reconnect as ONE
  carefully-guarded code path — research flags this as exactly the logic that gets
  almost-duplicated-correctly when merging two implementations.
- `visualCapture.stop()` is async and bounded (Phase 12's `stop(timeoutMs)`). Preserve
  the existing call discipline exactly: the combined release helpers release camera
  tracks synchronously FIRST then fire-and-forget the engine stop, while the end-of-
  session handler AWAITS `stop()` for the value it actually submits. Do not
  "simplify" this.
- **Checkpointing is type-declared.** Interview types checkpoint (fire-and-forget,
  ~9-15 times a session, same cadence and trigger as today). A type declaring no
  checkpointing must issue ZERO checkpoint calls. Do not add an unconditional
  checkpoint — that would make a case-study resumable where today it is not.
- The shell may call ONLY `/api/practice/session/*` and `/api/interaction/chat`. No
  `/api/interview/*` or `/api/scenario/*` literal paths.
- Termination: parse the marker via `parseEngineTurn` and honor the result only when
  the type's policy permits. With `avatarMayEnd: false` on all five of today's types,
  nothing can end a session but the student — unchanged behavior.
</non_negotiables>
