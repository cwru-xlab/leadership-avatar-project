<non_negotiables>
- **`components/interview/ReportScoreCards.tsx` and `components/report/ReportBody.tsx`
  are ALREADY SHARED and already receive identical props from both current pages. DO
  NOT TOUCH THEM.** They are the part of this stack that is already unified; research
  Section D says leave them completely alone. If the dimension-driven rendering needs
  something from `ReportScoreCards`, pass it as props the component already accepts —
  and if it genuinely cannot, STOP and raise it as a checkpoint rather than editing a
  shared leaf component.
- **Divergences to PRESERVE verbatim (REQ-69), diffed directly by the research:**
  - Interview: polls every **2000ms**, gives up at **120,000ms**, offers a manual
    **retry** (which calls the retry endpoint).
  - Scenario: polls every **3000ms**, gives up at **180,000ms**, offers a manual
    **"check again"** with NO retry endpoint call.
  - Interview's loader distinguishes a **401** (`needsLogin`) from a **404**.
    Scenario's has **no 401 branch at all** — only `notFound` — and additionally
    guards against re-polling after a 404 via a `hasLoadedOnceRef` the interview page
    does not have. Reproduce BOTH, including the asymmetry.
  - Only the interview report renders `ReportCustomizationStrip`. A scenario report
    must NOT gain one.
  **Adding 401 detection to scenario reports would be an unsanctioned visible change
  even though it is strictly an improvement.** Research Pitfall 7 calls this out by
  name. If a divergence turns out to be impossible to preserve, raise it as a
  checkpoint — do not pick a winner.
- Rubric rendering must be DIMENSION-DRIVEN: read the dimension list off the resolved
  type config and render each dimension's score from the `scores` map. No hardcoded
  `visual/vocal/content/behavioral` list in the page. A Phase 14 type adding
  `deck_quality` must render with zero page changes.
- Visual and Vocal keep their four-state handling (REQ-72). A missing score renders as
  its unscored reason, never as 0 and never as an invented number.
- Legacy rows: a pre-Phase-10 report (`cameraMode` null) must render exactly as it does
  today — "Not yet measured" without a synthesized reason.
- Do NOT edit the two old report pages. Plan 13-13 deletes them.
</non_negotiables>
