<objective>
Render every mode's outcome through the EXISTING `ReportChrome` extras slot,
descriptive and unscored, with no edit to the one report page.

Purpose: REQ-92 and P19-SC5. `ReportChrome.tsx`'s own header says it: "If you are
about to write `typeSlug ===` in the report page, add an extras entry here
instead." Phase 19 goes one step further — instead of four more `if (slug === ...)`
lines, the deck family resolves through one mode-table lookup, so a sixth mode
registers itself.

unscored outcome record and Phase 12's scored-vs-descriptive discipline): a tough
reviewer must never cost a well-run pitch points. `ReportDTO.outcome` is data the
report RENDERS — if you find yourself writing arithmetic that reads `outcome` and
writes a score, stop.

Output: one verdict panel component, mode-table-driven chrome, report titles and
the reports-list filter widened, and a verify script.
</objective>
