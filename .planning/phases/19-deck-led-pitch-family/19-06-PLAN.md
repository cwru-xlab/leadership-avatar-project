Create `FundingAskStep` exporting a value type
`export interface FundingAskValue { requestedAmountUsd: number; useOfFunds: string }`
and props `{ nav: SetupStepNav; value: FundingAskValue | null; onChange: (next: FundingAskValue | null) => void }`,
matching `NegotiationAskStep`'s shape.

Two fields:
  - **Amount requested (USD)** — numeric input with the same formatting and
    sanitation `NegotiationAskStep` applies to `askPriceUsd`. Must be a finite
    number greater than zero to advance.
  - **What it's for** — a short free-text "use of funds" textarea, with a visible
    character counter and a sensible max (pick one, state it in a comment, keep it
    in the 300-600 character range so it stays a summary and not a business plan).
    Must be non-empty after trimming to advance.

step.** A grant or budget request gives up no ownership (19-CONTEXT.md); equity is
absent as a concept, not zeroed. Do not copy `NegotiationAskStep`'s equity input
and hide or disable it — delete it from the copy.

Call `onChange(null)` while the input is incomplete so the wizard cannot assemble
a partial instance, and gate `nav`'s advance affordance exactly as
`NegotiationAskStep` does (same disabled-until-valid pattern, same inline helper
text explaining what is missing — no silent dead button).
