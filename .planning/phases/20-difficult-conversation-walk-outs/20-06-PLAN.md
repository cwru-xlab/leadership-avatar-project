<objective>
Make the report explain what tipped the conversation — quoted, with the session
clock — while guaranteeing in CODE that explicit content is never recited back
to the student.

Purpose: locked decision 7 is explicit that the sanitizer is a real code
requirement with its own test, not prompt guidance. An evaluator instructed not
to quote a slur is not a guarantee; this plan makes the guarantee hold even
when the evaluator disobeys. And because `ReportDTO.outcome` is passed through
as a generic record and narrowed in the browser by
`asConversationOutcome`, sanitizing only at render would still ship the
verbatim text in the page payload — so the transform belongs in `toReportDto`,
on the way out of the server.

Output: a pure sanitizer module, its application inside `toReportDto`, the
evaluator prompt aligned with it (belt as well as braces), and
`scripts/verify-dc-walkout-report.ts`.

  <action>
**Create `lib/difficult-conversation/quote-sanitizer.ts`** — pure, no I/O, no
model. File-top comment must state the contract plainly: this is the guarantee
that a slur is never recited back to the student, it runs server-side on the
way out, and the evaluator prompt is a courtesy, not the mechanism.

```ts
export interface SanitizedQuote {
  quote: string;
  /** True when the original was altered; report copy may acknowledge it. */
  sanitized: boolean;
}
export function sanitizeQuote(raw: string): SanitizedQuote;
export function sanitizeOutcomeQuotes(
  outcome: Record<string, unknown> | null,
): Record<string, unknown> | null;
```

`sanitizeQuote` rules, in order:
1. Classify with `detectHostility` from `@/lib/engine/hostility` — the SEVERE
   lexicon is the single source of what counts as explicit. Do not write a
   second private list; a divergence between the detector and the sanitizer is
   exactly the bug that would recite a slur back.
2. `tier === "severe"` → do NOT attempt partial redaction. Replace the WHOLE
   quote with a characterization drawn from the verdict's `matched` rule-group
   names, e.g. `"[a slur directed at the character — not repeated here]"` or
   `"[a sexually harassing remark — not repeated here]"`. Return
   `sanitized: true`. Characterizing beats masking here: a masked slur with the
   consonants intact is still a recitation.
3. `tier === "hostile"` → keep the quote. Hostility is the student's own
   behaviour and seeing it is the point of the report; only EXPLICIT content is
   withheld. Mask profanity inside it only if the severe lexicon matched a
   profanity sub-group; otherwise pass through unchanged, `sanitized: false`.
4. Always trim and hard-cap length (e.g. 240 characters with an ellipsis) so an
   evaluator cannot smuggle a paragraph into a quote field.
5. Never return the matched span, and never include the original text in the
   replacement.

`sanitizeOutcomeQuotes(outcome)` walks the outcome record and sanitizes only
the quote-bearing fields: parse `reactionCauses` (it may be a JSON string OR
an array — mirror `asReactionCauses`'s tolerance in `lib/report/dto.ts`),
sanitize each row's `quote`, preserve `timecodeSeconds` and `effect` exactly,
and re-serialize in the SAME representation it arrived in (string in → string
out) so no existing consumer breaks. Also sanitize `endTurnReasons` and
`inRoleReaction` the same way — those are free prose the evaluator writes and
they could quote the student verbatim too. Leave every other key untouched and
return the record unchanged when there is nothing to sanitize. Return `null`
for `null`.

**`lib/report/dto.ts`** — in `toReportDto`, change
`outcome: asOutcomeRecord(row.outcome)` to
`outcome: sanitizeOutcomeQuotes(asOutcomeRecord(row.outcome))`, with a comment
stating that this is the only exit from the server for an outcome record and
that the sanitizer must not be moved into a component: the verbatim text must
never reach a client payload. Do not change `asReactionCauses`,
`asConversationOutcome`, the `ReportDTO` shape, or anything else in the file.
If a layering rule forbids `lib/report/` importing `lib/difficult-conversation/`,
place the module at `lib/report/quote-sanitizer.ts` instead and record the move
in the SUMMARY — check the existing import directions first.
